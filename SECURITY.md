# Security policy

Axial is a language/toolchain beta. The supported public beta scope is the
frozen pure embed-v1 profile described in [docs/CLAIMS.md](docs/CLAIMS.md).
Other host and consumer profiles are experimental and are not certified for
production use. No version is currently declared a production security baseline.

Report suspected security issues privately to **contact@fermihart.com**.
Include the affected revision, profile, observed behavior, expected behavior,
and a safe description of impact. Do not publish credentials, customer data,
or operational exploitation details in a public issue. Please coordinate
disclosure before public discussion. No fixed response-time guarantee is made.

The maintainer will assess scope, preserve evidence, and publish a correction
and advisory when appropriate. Release qualification is described in
[docs/RELEASE-GATE.md](docs/RELEASE-GATE.md). A passing test is not a guarantee
that a product is free of defects.
